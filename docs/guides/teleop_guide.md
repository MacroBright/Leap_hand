# 👁️ 视觉手势遥操（Teleoperation）完全指南

本指南介绍如何使用 `Leap_Hand` 的视觉手势感知流水线进行实时单目/深度手势识别与真机遥操作。

---

## 1. 遥操工作原理与数据流

```text
[ RealSense D455 / 单目相机 (RGB / Depth) ]
                     │
                     ▼
[ hand_tracker.py : MediaPipe Hands (21 关节点三维坐标) ]
                     │
                     ▼
[ calibrator.py : 人手五指平摊自适应零点标定 ]
                     │ (归一化弯曲特征)
                     ▼
[ joint_mapper.py : 空间向量几何夹角解算 ]
                     │ (16 维原始目标弧度)
                     ▼
[ filter.py : OneEuroFilter 自适应时域滤波 (消除抖动，零相位延迟) ]
                     │ (平滑弧度)
                     ▼
[ motor_limits.json : 16 舵机物理限位安全裁剪 ]
                     │ (安全电机命令)
                     ▼
[ dynamixel_client.py : 4Mbps USB 同步写入 ] ──▶ [ 16 舵机实体动作 ]
```

---

## 2. 相机摆放与环境要求

| 考量项 | 最佳实践建议 |
| :--- | :--- |
| **相机机型** | 推荐 **Intel RealSense D455**；系统内置自动降级引擎，无 RealSense 时自动使用普通单目 WebCam |
| **摆放位置** | 桌面支架或三脚架，高度约与胸部平齐，镜头正对操作者 |
| **操作距离** | 距离手部 **0.4 ~ 1.0 m**（RealSense D455 最佳深度感知区间） |
| **手型朝向** | **手掌面向相机**，便于 MediaPipe 与 HaMeR 提取最稳定的三维骨骼 |
| **光照环境** | 均匀室内光照，避免强背光或直射强光引起皮肤反光与深度空洞 |

## 3. 实时单目/深度手势遥操：`leap-teleop`

### 3.1 启动命令

```bash
# 纯视觉预览模式 (无需连接实体灵巧手，适合验证手势算法与 HUD 界面)
leap-teleop

# 真机驱动模式 (通过 4Mbps USB 直连驱动实体手)
leap-teleop --drive

# 指定外部摄像头索引 (如接入多相机)
leap-teleop --drive --camera 1
```

### 3.2 键盘热键交互操作表

在遥操运行窗口内，支持以下实时交互热键：

| 按键 | 功能说明 |
| :---: | :--- |
| **`空格 (SPACE)`** | **一键自适应零点标定 & 硬件延迟上电**：五指完全张开平摊面向镜头按空格，完成标定并正式上电跟手 |
| **`L`** | **★ 姿态锁定 / 解锁 (Pose Lock)**：按 L 立即死锁保持灵巧手当前姿态；再次按 L 解锁恢复实时视觉跟随 |
| **`D`** | **切换诊断 HUD 覆盖层**：显示 16 个舵机目标转角、当前弯曲手指判定高亮与 FPS |
| **`Tab`** | **轮转切换选定舵机**（0 ~ 15 号）：选中后可在画面中单独查看该舵机状态 |
| **`[` / `]`** | **实时增减选定舵机增益 (Gain)**：微调该舵机动作灵敏度（步长 $\pm 0.05$） |
| **`S`** | **持久化保存增益**：将当前微调好的增益参数写入 `configs/joint_gain.json` |

| **`R`** | **重置当前舵机增益**：将当前舵机增益重置为默认值 1.0 |
| **`Q` / `ESC`** | **安全退出**：灵巧手自动平滑复位回全开位并断开连接 |

## 4. 3D 多源高精度手势遥操：`leap-teleop-3d`

解决单目手势在**手部倾斜、旋转或握拳遮挡时伪 3D 深度畸变**的问题。

### 4.1 启动命令
```bash
# 启动 3D MANO / 多源遥操
leap-teleop-3d

# 启动真机驱动
leap-teleop-3d --drive
```

### 4.2 三源切换机制（按 `M` 键）
在画面中按下 **`M`** 键，可实时热切换三种 3D 姿态源：
1. **`HAMER 3D`**：基于 Transformer 与 MANO 模型的单目 3D 网格重建，精度最高，抗自遮挡能力强；
2. **`WORLD 3D`**：MediaPipe 规范化米制三维关键点模型，帧率最高，稳定性优；
3. **`MP PSEUDO-3D`**：经典相对深度伪三维。

## 5. 滤波参数调优建议（OneEuroFilter）

系统采用一欧元滤波器（$1€$ Filter）平衡**静态防微抖**与**动态快速响应**：
- `min_cutoff`（默认 1.0 Hz）：静止状态下的截止频率，值越小静态越平滑（抖动消除越彻底）；
- `beta`（默认 0.007 ~ 0.02）：速度增益系数，手部快速挥动时自动抬高截止频率，消除跟踪相位滞后。
可在 `leap_hand.cli.teleop` 或初始化参数中按需微调。
