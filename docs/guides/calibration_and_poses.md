# 🎯 姿态标定与姿态数据库指南

本指南介绍 LEAP Hand 的零点标定流程、姿态数据库格式、编码器 $2\pi$ 跨圈解回绕算法以及安全防护机制。

---

## 1. 为什么需要真机零点标定？

由于每台 LEAP Hand 的 3D 打印结构件装配公差、齿轮啮合间隙以及舵机安装零位存在微小差异，**所有关节控制必须以真机实测的全开位（`OPEN_POSE`）为绝对基准**。

如果使用理论默认值，可能造成：
1. 手指无法完全伸直或反向过度绷紧；
2. 抓握或推拿手法的关节计算累积偏差。

---

## 2. 标定与姿态录制工具：`leap-calibrate`

运行命令：
```bash
leap-calibrate
```

终端将弹出主菜单：
```text
╔══════════════════════════════════════╗
║   LEAP Hand 校准 & 录制              ║
╠══════════════════════════════════════╣
║  1. 校准 (重录全开位)                ║
║  2. 录制 (录/重录姿势)               ║
╚══════════════════════════════════════╝
```

### 2.1 选项 1：重录全开位（OPEN_POSE）
1. 终端提示后，舵机扭矩将自动释放（手指可自由活动）；
2. 人工用双手将机械手的 4 根手指完全展开、伸平，拇指外摆到完全自然平直位置；
3. 在终端按下 `Enter`，程序自动连续采样、验证并更新 `configs/poses.json` 中的 `全开/平伸` 条目；
4. 随后舵机自动恢复扭矩并平滑吸合在新的全开位。

### 2.2 选项 2：录制自定义姿态（如推拿揉法/捏取等）
1. 人工摆动机械手指到目标手法姿势（例如二指拿捏、大拇指按压）；
2. 键入姿势名称（例如 `按摩揉法` 或 `pinch_index`）；
3. 保存后，该姿势自动存入数据库，可在 Python 代码中通过 `leap.set_pose("按摩揉法")` 直接调用。

## 4. 关键安全与滤波算法

### 4.1 编码器 $2\pi$ 跨圈自动解回绕（Unwrap to Limits）
Dynamixel 磁编码器在 $0 \sim 4096$（$0 \sim 2\pi$）之间循环计数。当关节在零点边界微动时，可能发生由 $0.05$ 突变到 $6.23$ 的假象跨圈跳跃。
`leap_hand.controller.pose_manager.unwrap_to_limits` 以 `motor_limits.json` 的实测机械中点作为稳定锚点：
- 若读数与锚点偏差 $> \pi$，自动平移 $-2\pi$；
- 若读数与锚点偏差 $< -\pi$，自动平移 $+2\pi$；
彻底消除编码器跨圈导致的舵机暴力旋转。

### 4.2 坏数据拦截安全门（`is_valid_pose`）
当串口偶发高频通信丢帧或超时返回全零缓存时，`is_valid_pose` 会实时拦截：
1. 拦截全零或常数向量；
2. 校验读数是否在 $[-2.5, 8.5]$ rad 合理运动包络内；
3. 若全开位无效，控制器触发安全门熔断，**强制拒绝驱动电机**，杜绝误动损毁。
