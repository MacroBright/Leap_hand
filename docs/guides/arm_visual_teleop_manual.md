## 一、相机正确摆放位置

| 项 | 建议 |
|----|------|
| **位置** | 桌面支架/三脚架，面向操作者，**高度约胸部**（相机大致水平） |
| **距离** | 手保持在相机 **0.4 ~ 1.0m**（D455 深度甜点，太近 <0.28m 深度失效，太远手太小） |
| **手在画面** | 手在**画面中心区域**（边缘深度/畸变差） |
| **手型朝向** | **手掌大致朝向相机**（正面看手）——掌法线 f/n/lat 测量最稳、翻转/俯仰最灵敏 |
| **光照** | 避免强背光/反光（皮肤反光 → 深度噪声） |
| **固定** | 标定完 R 后**相机不能动**（一动 R 就失效，需重标定） |

**摆放后测试**：手移到画面中心，看 HUD `depth=` 是否在 400-1000mm 且稳定（不跳变）——这是深度正常的标志。

## 二、手 → 机械臂运动对应表（6DOF 架构）

> 具体**方向**取决于 K 标定的手眼 R。下表是"操作时应该感受到的对应"（若某项反向，说明对应方向码选错，重做 K 向导）。

### 位置（末端平移）— 3DOF

| 你的手 | 相机看到 | 末端预期 |
|--------|---------|---------|
| 手**向右**移 | 画面向右 | 末端向右平移 |
| 手**向上**抬 | 画面上移 | 末端向上平移 |
| 手**靠近相机** | 深度减小 | 末端向前（远离基座）平移 |
| 手**远离相机** | 深度增大 | 末端向后平移 |

### 姿态（末端旋转）— 3DOF

| 你的手 | 姿态变化 | 末端预期 |
|--------|---------|---------|
| **翻转手掌**（旋前/旋后，像拧螺丝） | 掌法线 n 绕手前向 f 旋转 | 末端绕**工具轴**旋转 |
| **手腕上翘/下压**（手掌与小臂夹角变） | 指尖方向 f 俯仰 | 末端**抬头/低头** |
| **手腕左右摆**（偏航） | 指尖方向 f 偏航 | 末端**转头/摆头** |

### 使能/停止

| 操作 | 效果 |
|------|------|
| **按住 H** | 捕获手锚点+末端锚点，开始跟随（手位姿增量→末端目标） |
| **松开 H** | 重新锚定，末端停在当前位置（走哪停哪） |
| **手移出视野/丢失** | 速度清零，末端保持 |

## 三、标准操作流程

```
1. 摆放相机（§一）→ 启动仿真 + demo
2. 按 K 做轴对齐校准（3 步挥动 + 方向码 + Z 验证）
3. 手放画面中心，按 H 锚定
4. 移动手 → 末端位置跟随（若反向 → 重做对应 K 步骤）
5. 翻转/俯仰/摆动手 → 末端姿态跟随（若反向/不跟 → 见 §四）
6. 松开 H → 末端停住
7. 需要时：R 复位、M 录制复位点、C 重载标定
```

## 四、姿态延迟/不跟手的调优

| 可能原因 | 调整 |
|---------|------|
| **k_ang 太小**（姿态环慢） | `demo` 里 `WristTracker(k_ang=...)` 默认 0.05（可调到 0.05~0.1） |
| **滤波滞后** | `WristTracker(min_cutoff=...)` 默认 4.0 → 可 6.0（姿态比位置更吃滤波） |
| **DLS IK 阻尼** | `IK_DAMPING=0.05`（仿真 mujoco_sim.py）→ 可试 0.02（更跟手、略抖） |
| **手翻转幅度小** | 操作时翻转幅度大些（姿态环死区 2°） |
| **标定 R 不准** | 重做 K 校准（姿态方向映射依赖 R） |
| **深度/掌法线噪声** | 手保持在 0.4-1.0m、画面中心、掌心朝相机 |

## 五、按键速查

| 按键 | 功能 |
|------|------|
| **H** | 离合器（按住跟随，松开重锚定） |
| **M** | 录制复位点（1-6 选关节，W/↑正转，X/↓反转，S 保存到 home_pose.json） |
| **R** | 复位（回手动复位点或默认初始位） |
| **C** | 重载 handeye_calib.json |
| **K** | 轴对齐校准向导（3 步 + Z 验证） |
| **Y** | e_stop 急停 |
| **Q / ESC** | 退出 |
